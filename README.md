# Joma Logistics Incorporated AI Website

Vercel-ready Next.js website for www.jomainc.com.

## Pages
- Home
- AI Customs Chatbot
- Upload Documents
- AI Duty Calculator
- Shipment Tracking
- Contact

## Deploy to Vercel
1. Upload this folder to GitHub.
2. Go to Vercel > Add New Project.
3. Import the GitHub repository.
4. Framework Preset: Next.js.
5. Click Deploy.

## Domain
In Vercel > Project > Settings > Domains, add:
- www.jomainc.com
- jomainc.com

Then update DNS at GoDaddy using Vercel instructions.

## Email
For tim@jomainc.com, use Google Workspace or GoDaddy Professional Email.
Update MX records after the email service provides them.
