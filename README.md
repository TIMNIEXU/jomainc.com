# Jomainc.com Reorganized Website

Next.js website for Joma Logistics Incorporated.

## Local run
npm install
npm run dev

## Deploy to Vercel
1. Upload/push this folder to GitHub.
2. Import the GitHub repository in Vercel.
3. Framework preset: Next.js.
4. Deploy.

## Main files
- app/page.tsx: Homepage content and layout
- app/globals.css: Website styling
- components/LanguageToggle.tsx: English/Chinese language switcher
- components/UploadBox.tsx: Front-end upload UI placeholder
- components/QuoteForm.tsx: Quote request form UI
- lib/content.ts: All bilingual website text
